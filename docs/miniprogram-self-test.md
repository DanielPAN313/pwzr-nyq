# 宁约球小程序自测清单

更新时间：2026-07-06

当前版本是 UI-first 版本，以 `origin/ui-polish` 的 7 页界面为主。

## 1. 启动前检查

```bash
git status --short --branch
npm run check
npm run dev
```

微信开发者工具导入：

```text
目录：pwzr-nyq/miniprogram
AppID：touristappid
后端服务：不使用云服务
```

## 2. 页面检查

启动页：
- 能看到宁约球动效启动页。
- 约 1.9 秒后自动进入首页。

首页：
- 能看到 `Book your court` 主视觉。
- 点击搜索条能跳到订场页。
- 今日状态能显示加载、错误或统计摘要。

订场页：
- 能加载真实场馆列表或兜底场馆。
- 点击真实场馆的订场按钮，会尝试生成待支付订单并跳到订单页。
- 后端关闭时能显示兜底场馆和错误提示。

球局页：
- 能加载真实球局列表或兜底球局。
- 可报名球局点击报名后能调用报名接口。
- 报名成功后能刷新列表。

消息页：
- 能加载通知列表或兜底消息。
- 点击真实消息能标记已读。

我的页：
- 能加载个人概览。
- 我的订单入口能打开订单页。
- UI 版暂未开放入口点击后有提示，不应无反应。

订单页：
- 能加载订单列表或兜底订单。
- 能展示订单状态、金额和核销码。

## 3. 通过标准

- `npm run check` 通过。
- 微信开发者工具编译不报错。
- 底部 5 个 tab 都能打开。
- 所有可点击按钮有跳转、请求或提示，不出现静默无反应。
