# 宁约球小程序自测清单

更新时间：2026-07-06

当前版本是 UI-first 版本，以 `origin/ui-polish` 最新主界面为主，并已恢复旧功能闭环到 16 页产品流。

## 1. 启动前检查

```bash
git status --short --branch
npm run check
npm run dev
```

微信开发者工具导入：

```text
目录：pwzr-nyq/miniprogram
AppID：touristappid
后端服务：不使用云服务
```

## 2. 页面检查

启动页：
- 能看到宁约球动效启动页。
- 约 1.9 秒后自动进入首页，开发阶段跳过强制登录。

注册页：
- 邮箱、账户名、密码为空时有提示。
- 邮箱格式不正确或密码不足 6 位时有提示。
- 填写有效信息后能调用注册接口，成功后进入首页。
- 点击登录账号能打开登录页。

登录页：
- 用户名或密码为空时有提示。
- 填写信息后能调用登录接口，成功后进入首页。
- 记住我没有本地账号时有提示。

首页：
- 能看到 `Book your court` 主视觉。
- 首屏快捷入口能打开订场、球局、订单、消息。
- 好友邀请 / 正在招人切换有动效。
- 球局卡片倒计时会刷新。
- 后端可用时卡片能接入真实球局数据；后端关闭时保留 UI 兜底示例。

订场页：
- 能加载真实场馆列表或兜底场馆。
- 能按场馆名、区域或运动类型搜索。
- 点击详情能打开场馆详情页。
- 点击真实场馆的订场按钮，会尝试生成待支付订单并打开订单页。
- 后端关闭时能显示兜底场馆和错误提示。

场馆详情页：
- 能加载场馆开放时段。
- 能切换日期和选择可预约时段。
- 能复制地址；有坐标时能打开地图导航。
- 点击订场能生成待支付订单并进入订单页。

球局页：
- 能加载真实球局列表或兜底球局。
- 能按球局、场地、状态或费用搜索。
- 点击发起球局能打开发起球局页。
- 点击详情能打开球局详情页。
- 可报名球局点击报名后能调用报名接口。
- 报名成功后能刷新列表。

发起球局页：
- 能加载场馆列表。
- 标题、场馆、时间、人数和费用校验清晰。
- 发布成功后能进入球局详情页。

球局详情页：
- 能展示报名进度、球友状态和下一步提示。
- 互评开放时能提交赛后互评。

消息页：
- 能加载通知列表或兜底消息。
- 点击真实消息能标记已读。

我的页：
- 能加载个人概览。
- 我的订单入口能打开订单页。
- 我的球局、信用分、场馆端、支付与规则入口都能打开。

订单页：
- 能加载订单列表或兜底订单。
- 能展示订单状态、金额和核销码。
- 待支付订单能触发预支付和支付确认。
- 可取消订单有确认弹窗，成功后刷新列表。
- 可核销订单能发起到场核销。
- 核销码能复制，空订单有去订场和找球局入口。
- 已核销且关联球局的订单能进入赛后互评。

场馆端：
- 无场馆时能提交入驻申请。
- 有场馆时能维护价格、联系方式和开放时段。
- 能扫码或输入核销码完成核销。

信用分：
- 能展示当前信用分、信用事件和相关入口。

我的球局：
- 能查看已报名、待处理和历史球局。
- 能进入球局详情或发起球局。

## 3. 通过标准

- `npm run check` 通过。
- 微信开发者工具编译不报错。
- 底部 5 个 tab 都能打开。
- 注册页和登录页能通过编译模式或手动跳转打开。
- 所有可点击按钮有跳转、请求或提示，不出现静默无反应。
